# 📡 Эхолот

**Лабиринт в полной темноте: звуковая волна на секунду показывает стены, но твари идут на звук.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/echo/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Процедурный лабиринт с петлями (DFS + случайные проходы)
- Звуковая волна подсвечивает стены, выход и тварей
- ИИ тварей: блуждание, охота на звук пинга, слух шагов (BFS)
- Звуки синтезируются Web Audio, звёзды за экономию пингов
- Управление: клавиатура, свайпы и кнопки на телефоне

## Стек

JavaScript, Canvas, Web Audio. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/echo.git
cd echo
python3 -m http.server 8000
```
